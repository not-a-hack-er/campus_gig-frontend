## Full description

CampusVault is a student-focused gig marketplace built for campus communities.

Discover opportunities that match your skills, post work you need help with, apply to gigs, collaborate through real-time messaging, and build your reputation with verified reviews.

Key features:

• Browse and search campus gigs by category and skill
• Create gigs with clear budgets, deadlines, and requirements
• Apply with a proposal and track application progress
• Message students in real time
• Receive in-app and push notifications for important activity
• Build a profile with your college, branch, year, skills, links, resume, and photo
• Join student communities and share useful posts
• Confirm gig completion with a secure OTP workflow
• Review completed collaborations

CampusVault helps students learn, earn, and collaborate in one focused platform.

## Data safety draft (verify in Play Console)

Data types used by core app features include name, email address, profile/education details, user-generated content, messages, photos/files, app activity, and an FCM device token. Data is encrypted in transit. Users can request deletion in-app or at the account-deletion URL. The app does not sell user data and does not contain ads.
